Finora REST API Overview

The Finora API allows developers and financial institutions to query real-time credit score factors, simulate financial growth scenarios, and generate AI insights via standard JSON over HTTPS.

https://finora.ai/api/v1/credit-score/analyze/

Authentication

All API requests must pass a valid Bearer JWT token in the Authorization header:

Authorization: Bearer <YOUR_API_JWT_TOKEN>
Content-Type: application/json

Available API Endpoints

  • GET /api/credit-score/summary/ — Fetch current user credit score & metrics
  • POST /api/assistant/chat/ — Send prompt to Groq-powered AI Assistant
  • GET /api/reports/summary/ — Generate monthly PDF/JSON tax statement
  • POST /api/simulator/predict/ — Run Monte Carlo financial simulation
